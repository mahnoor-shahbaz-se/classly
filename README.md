# Classly

A smarter way to learn, together.

Classly is a redesign of the online classroom experience, inspired by Google Classroom. It brings classes, assignments, resources, deadlines and progress into one simple learning space. Built with HTML, CSS and JavaScript, no frameworks.

Live Demo: https://mahnoor-shahbaz-se.github.io/classly/

## Features

- Dashboard with class progress and upcoming deadlines
- Classes with Stream, Classwork and People tabs
- Assignments with a Turn in / Unsubmit flow
- Calendar with monthly navigation
- To-Do list saved in the browser
- Grades and progress overview
- Sign Up and Log in with form validation
- Help Center, Privacy Policy, Terms of Use and a 404 page
- Responsive on desktop, tablet and mobile

## Run locally

1. Download or clone the repository
2. Open `index.html` in your browser

## Note

This is a front-end design project. Sign Up and Log in are not connected to a real backend, so do not enter real passwords.
